# Ziyuan Chen — Academic Homepage

Static personal academic website for Ziyuan Chen, hosted with GitHub Pages.

## Local preview

Open `index.html` directly, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Updating the site

- Edit profile text in `index.html`.
- Replace `assets/profile.jpg` to update the portrait.
- Push changes to `main`; GitHub Pages publishes the site from the branch automatically.
